## Website presentation

The conceptual scene SVG, favicon, layout, controller walkthrough, and native browser animations were created for this project page. The scene and controller examples are explanatory illustrations, not model outputs or experimental observations.

DIWA provided a visual reference for a light background, restrained borders, whitespace, and clear hierarchy. The page uses an original implementation; no DIWA code, artwork, or assets are included. The paper's original Figure 1 and Figure 2 are clearly identified separately from the conceptual illustrations.

The delivered page uses system fonts and native HTML, CSS, SVG, and JavaScript. It does not load font services, animation libraries, icon libraries, analytics, or other third-party runtime packages from a CDN.
